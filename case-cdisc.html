跨国药企 CDISC 标准数据集交付

受某跨国药企委托，梅斯医学与其 Global 团队无缝协作，交付符合 FDA 递交标准的 SDTM / ADaM / Define.xml 标准数据集与 TFLs，支撑全球 NDA / BLA 注册申报。

※ 客户名称、治疗领域及化合物信息已脱敏
合作模式
Global 团队远程协同遵循 FDA 技术规范
交付范围
SDTM / ADaM / Define.xml含 TFLs 输出
合规验证
Pinnacle 21 校验 100%零 conformance issue
交付成果
纳入全球申报包NDA / BLA 提交
📋

需求对齐与 Spec

确认 SAP / Shell、ADaM 元数据与变量词典，对齐递交要求。

🗂️

SDTM 标准化

原始库按 CDASH 映射至 SDTM 通用 / 专用 domain。

🧮

ADaM 分析数据集

构建 ADSL / ADAE / ADTTE 等分析数据集与衍生变量。

📑

Define.xml + aCRF

生成定义文件与注释 CRF，确保数据可溯源可核查。

📊

TFL 与双编程验证

TFL 输出 + 独立双编程 + Pinnacle 21 合规核查。

🌐

标准合规

严格遵循 CDISC（SDTM IG / ADaM IG）、FDA 技术规范与 21 CFR Part 11 电子记录要求。

🔍

质量体系

双编程验证、独立 QC 复核、完整变更与审计轨迹，结果可重复可追溯。

✅

监管认可

数据集与 TFLs 被纳入全球申报包，P21 校验零问题，经得起 FDA 核查。

脱敏说明：客户名称（某跨国药企 Global 团队，按客户要求隐去）；具体治疗领域、化合物及研究中心（统称"跨多治疗领域全球多中心项目"，不予披露）。方法学遵循 CDISC、FDA 技术规范、ICH 及 21 CFR Part 11 要求。
